# 3층 오목

〈피의 게임 X〉에 나온 **3층 오목**을 웹에서 2인(한 화면) 대전으로 즐길 수 있게 만든 최소 기능 버전입니다.

```bash
npm install
npm run dev      # 개발 서버
npm test         # 규칙 엔진 단위 테스트
npm run build    # 타입체크 + 프로덕션 빌드
```

## 규칙

- **게임판**: 삼각형 격자(교차점마다 6방향 인접)로 된 육각형 판. 플레이어마다 돌 25개.
- **기본 배치**: 흑 1 → 백 2 → 흑 2 → 백 1. 정중앙, 그리고 자신이 놓은 돌과 인접한 칸에는 둘 수 없다.
- **차례**: 흑부터 번갈아 아래 중 하나를 한다.
  - 돌 놓기: 빈 칸에 내 돌 1개를 놓는다.
  - 돌 이동: 맨 위가 내 돌인 더미에서 맨 위 돌 1개를 인접 칸으로 옮긴다. 다른 돌(상대 돌 포함) 위에 쌓을 수 있다.
- **쌓기 제한**: 최대 3층. 출발 더미보다 높은 더미 위로는 이동할 수 없다.
- **승리** (게임판을 위에서 봤을 때, 즉 각 칸의 맨 위 돌 기준)
  1. 한 방향으로 정확히 5개 연속 (6목 이상은 인정하지 않음)
  2. 3층에 내 돌 5개
  3. 3층에서 인접한 세 칸이 모두 내 돌
- 두 플레이어가 동시에 조건을 만족하면 그 차례를 진행한 플레이어가 승리한다. 돌을 옮겨 아래 돌이 드러나면서 상대만 조건을 만족하면 상대가 승리한다.
- 아래층 돌은 색을 숨기고 높이만 보여준다(방송의 암기 요소).

### 구현 시 가정한 부분

공개 자료에서 확인하지 못해 임의로 정한 부분입니다. 방송 화면 기준으로 다르면 알려주세요.

| 항목 | 현재 구현 | 위치 |
| --- | --- | --- |
| 게임판 크기 | 한 변 6칸(반지름 5)의 육각형, 91칸 | `DEFAULT_CONFIG` in `src/game/rules.ts` |
| 이동 높이 제한 | 도착 더미 높이 ≤ 출발 더미 높이(이동하는 돌 포함) | `moveTargets` |
| 인접한 3층 3개 | 3층 내 돌이 서로 이어진 덩어리 3칸 이상(일직선·삼각형 모두 인정) | `findThreeAdjacent` |
| 둘 곳이 없을 때 | 무승부 | `applyAction` |
| 시간제한 | 없음 | — |

## 구조

```
src/
  game/
    board.ts        # 축 좌표계(axial) 기반 육각형 판, 인접/직선 방향
    rules.ts        # 순수 함수 규칙 엔진: createGame, canPlace, moveTargets, checkWin, applyAction
    rules.test.ts
  useGame.ts        # useReducer + 히스토리(되돌리기), 클릭 → 액션 해석
  components/
    Board.tsx       # SVG 게임판
    StatusPanel.tsx # 차례/남은 돌/버튼/규칙
```

규칙 엔진은 React와 분리된 순수 함수라 AI 대전·온라인 대전(서버 검증) 등으로 확장할 때 그대로 재사용할 수 있습니다.
